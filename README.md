🗂️ Автоматизация ввода в модальных формах Vaadin

Browser Automation / Content Script Portfolio Project | Live Demo | GitHub
🎯 Цель проекта

Разработать переиспользуемый content script для автоматизации работы с модальным диалогом добавления документа в SPA на базе Vaadin (GWT): предсказание ввода ФИО, маскирование дат, кастомная Tab-навигация и валидация в реальном времени — с сохранением статистики между сессиями.
🚀 Технологический стек
Технология	Применение в проекте
JavaScript (ES2020+)	Замыкания, Map/Set, optional chaining, Object.freeze
Web Storage API	Персистентность статистики частотности имён (localStorage)
MutationObserver API	Отслеживание появления динамических диалогов в SPA
DOM Events API	input, keydown, blur, кастомные Event с composed: true
Vaadin / GWT	Работа с класс-селекторами v-textfield, v-window, v-button
📊 Демонстрируемые навыки
1. Работа с динамическим DOM

    ✅ MutationObserver — ожидание появления диалога с таймаутом (защита от утечек)

    ✅ Событийная синхронизация — эмуляция Vaadin value-change для корректной работы фреймворка

    ✅ Изоляция UI — попап-подсказки с position: fixed и z-index: 100000

    ✅ Экранирование HTML — защита от XSS при рендере пользовательских значений

2. Архитектурные решения

    ✅ IIFE-инкапсуляция — публичный API без загрязнения глобального пространства

    ✅ Единый источник конфигурации — SETTINGS с селекторами, таймингами и ограничениями

    ✅ Модульная структура — независимые блоки для хранения, UI, валидации, клавиатуры

    ✅ Object.freeze для паттернов — защита регулярных выражений от случайной мутации

3. UI/UX компетенции

    ✅ Предиктивный ввод ФИО — до 5 подсказок с бейджами частоты (×N) и пола (♂/♀)

    ✅ Управление с клавиатуры — ↑/↓ навигация, Enter — принять, Esc — закрыть

    ✅ Маска дат — авто-расстановка точек, корректная обработка Backspace/Delete на разделителях

    ✅ Визуальная валидация — красная обводка только при blur и непустом значении

    ✅ Защита от случайной отправки — блокировка Enter на невалидной форме

4. Алгоритмические навыки

    ✅ Нормализация ключей — опциональное сведение ё → е для дедупликации имён

    ✅ Определение пола по трём признакам — фамилия → имя → отчество с приоритетом

    ✅ Ранжирование кандидатов — по полу, частоте и алфавиту в одной сортировке

    ✅ Пересчёт позиции каретки — countDigitsBefore / caretFromDigitCount для масок

    ✅ Дебаунс предикта — 80 мс через predictionTimer

🏗 Архитектурные принципы
Структура приложения:
text

Content Script (IIFE)
├── SETTINGS / PATTERNS         — декларативная конфигурация
├── nameFrequencyStore          — хранилище частотности + persist
│   ├── frequencies[3]          — Map на фамилию / имя / отчество
│   └── genderMap[3]            — Map пола по ключам
├── suggestionPopup             — UI-попап с предиктами
├── domUtils                    — эмуляция событий Vaadin
├── fieldValidators / inputFilters
├── configureField / configureContentField
├── keyboardActions             — Tab-навигация, Enter-логика
└── setupDocumentDialog / watchForDocumentDialog

Ключевые паттерны:

    Единый источник конфигурации — все селекторы, тайминги и ограничения в SETTINGS

    Замыкание с инкапсуляцией — nameFrequencyStore экспортирует только публичный API

    Strategy через объекты — fieldValidators, inputFilters, keyboardActions как наборы стратегий

    Separated Concerns — валидация, рендер, обработка клавиатуры и оркестрация разделены
